# Simple Interest Calculator

A small Bash command-line program that calculates simple interest from a principal amount, an annual rate of interest, and a time period.

## Formula

```text
Simple Interest = (Principal × Rate × Time) / 100
```

## Inputs

- **Principal**: the starting amount
- **Rate**: annual interest rate, as a percentage
- **Time**: duration in years

## Usage

Run the script in a Bash-compatible terminal:

```bash
bash simple-interest.sh
```

Enter the requested values when prompted. The calculator prints the simple interest and total amount (principal plus interest).

## Example

For a principal of `1000`, an annual rate of `5%`, and a time period of `2` years:

```text
Simple interest: 100
Total amount: 1100
```

## Requirements

- Bash
- A terminal
